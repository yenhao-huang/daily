## NVIDIA Developer Blog

### Setting a World Record for MoE Pre-Training on NVIDIA GB300 NVL72

- **日期：** 2026-07-21
- **摘要：** NVIDIA 表示 GB300 NVL72 在 DeepSeek-V3 671B 的 MoE 預訓練中達到每 GPU 1,648 TFLOPS，創下其所稱的世界紀錄。文章強調 MoE 每 token 計算量下降後，跨數千顆 GPU 的通訊效率已成為擴展瓶頸，因此成果仰賴運算、網路與軟體的共同設計。

- **影響：** 大型 MoE 訓練的競爭焦點正從單純算力轉向整櫃互連與通訊堆疊效率。

- **原文連結：** 📎 https://developer.nvidia.com/blog/inside-nvidia-vera-cpu-olympus-cores-built-for-maximum-single-threaded-performance-in-agentic-ai/
- **影響：** AI 基礎設施的瓶頸將更明顯地延伸至 CPU，促使 GPU、CPU 與網路採整體協同設計。

- **日期：** 2026-07-21

## Apple Machine Learning Research

### Environment-free Synthetic Data Generation for API-Calling Agents

- **日期：** 2026-07-21
- **摘要：** Apple 提出不需完整可執行環境的 API 代理合成資料方法，只憑 API 規格就由 LLM 即時模擬具狀態的數位世界並產生互動軌跡。這避開建立真實後端、預填資料庫與大量環境實作的成本瓶頸。
- **原文連結：** 📎 https://machinelearning.apple.com/research/environment-free
- **影響：** 若合成軌跡品質足夠，工具型代理的訓練資料擴展速度可大幅提升，但也更需要驗證模擬偏差。

### Accelerating Text-to-Video Generation with Calibrated Sparse Attention

- **日期：** 2026-07-21
- **摘要：** 研究觀察到文字轉影片擴散模型中，許多 token 連結跨輸入持續呈現極低注意力分數，且模式會在查詢間重複。透過校準後跳過這些 token 或局部區塊連結，可減少時空注意力計算，同時盡量維持生成品質。
- **原文連結：** 📎 https://machinelearning.apple.com/research/calibrated-sparse-attention
- **影響：** 稀疏注意力若能穩定落地，將降低高解析、長影片生成的延遲與算力成本。

### RayRoPE: Projective Ray Positional Encoding for Multi-View Attention

- **日期：** 2026-07-20
- **摘要：** RayRoPE 為多視角 Transformer 設計以投影射線為基礎的位置編碼，透過射線上的預測點而非僅使用方向來表達影像 patch。方法力求同時提供唯一定位、SE(3) 不變注意力、多頻相似性與對場景幾何的適應能力。
- **原文連結：** 📎 https://machinelearning.apple.com/research/rayrope-projective-ray
- **影響：** 更貼近三維幾何的位置編碼，有望改善多視角重建、空間理解與機器人視覺模型。
