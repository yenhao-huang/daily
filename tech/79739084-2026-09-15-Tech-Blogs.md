# 每日科技部落格摘要｜2026-09-15

整理範圍：NVIDIA、Google、OpenAI、Meta、Apple 與 Anthropic 的官方技術與研究更新。

## NVIDIA Developer Blog

### [Accelerating Dropless MoE Training in JAX with NVIDIA Transformer Engine](https://developer.nvidia.com/blog/accelerating-dropless-moe-training-in-jax-with-nvidia-transformer-engine/)

日期：2026-09-14

NVIDIA 說明如何將 Transformer Engine、JAX 與 NCCL expert parallelism 結合，讓不丟棄 token 的 MoE 訓練能有效處理不規則的專家負載。其 DeepSeek-V3 671B 範例透過 grouped GEMM、MXFP8、主機端 activation offloading 與多串流 collective，將每 GPU 吞吐量由 103 提高到 1,068 TFLOPS，並在 1,024 張 GPU 維持 97% 擴展效率。

影響：MoE 訓練的瓶頸正從單一模型核心延伸到跨 GPU 的資料搬移與排程；可重現的 JAX 最佳化路徑有助於大型模型團隊降低規模化成本。

## Google Research

### [ToolGrad: Efficient tool-use dataset generation with textual "gradients"](https://research.google/blog/toolgrad-efficient-tool-use-dataset-generation-with-textual-gradients/)

日期：2026-09-10

Google 提出 ToolGrad，以「先生成可驗證的工具呼叫鏈、再生成使用者問題」取代傳統由問題出發的搜尋式資料標註。框架讓 API proposer、executor、selector 與 LLM updater 反覆擴展工作流，Google 報告其資料生成通過率可達 99.8%，以 ToolGrad-500 微調的 12B 模型在未見工具的評測上具競爭力。

影響：可驗證軌跡優先的合成資料，可能讓 agent 的工具使用後訓練更便宜、可規模化，並降低依賴人工標註的程度。

## Google Developers Blog

### [Autonomous LLM post-training with Tunix on TPUs](https://developers.googleblog.com/autonomous-llm-post-training-with-tunix-on-tpus/)

日期：2026-09-11

Google 展示以 Tunix、Gemma、Cloud TPU 與 agent 迴圈組成的 `autofinetune`，讓代理依 Markdown 規格自動調整 LoRA、學習率、batch size 等參數，量測後保留提升或回退失敗變更。範例中，SFT 在 TPU v5e-1 上於數小時內跑完 20 次實驗；Gemma 3 1B 的 GRPO 設定則在 2 到 3 天完成 40 次實驗。

影響：將模型後訓練包裝成有界、可審計的自動實驗迴圈，可把研究人員從重複的超參數掃描轉向定義目標與安全邊界。

## OpenAI News

### [Rapidly scaling online storage to serve over 1 billion ChatGPT users](https://openai.com/index/scaling-storage-one-billion-users-part-one/)

日期：2026-09-11

OpenAI 介紹線上儲存平台 Habitat，從 DevDay 2023 時的一個 Python client library 演進為服務層，替 ChatGPT、API、Codex 與內部服務處理資料定位、授權、快取與隔離。該平台目前每秒處理逾 7,000 萬請求、服務每週逾 10 億使用者，管理超過 500 PB 資料並覆蓋近 40 個地區。

影響：AI 產品的能力擴張也仰賴資料平面的可靠性；此案例凸顯多租戶、資料駐留與讀取效能已是模型之外的核心競爭面。

### [Now everyone can put data to work](https://openai.com/index/put-data-to-work/)

日期：2026-09-10

OpenAI 宣布 ChatGPT Work 的 Data agent 可連接 AWS、ClickHouse、Databricks、Snowflake、MongoDB、Redis 與 G2 等資料來源，並尊重既有表格、欄位與列級權限。使用者可用自然語言追問、檢視證據、建立可分享的互動式儀表板，也可在 Omni、Power BI、Tableau 等 BI 工具中延續工作。

影響：把受治理的企業資料直接置入工作對話，能縮短分析到決策的路徑，但也提高了資料權限配置與證據可追溯性的必要性。

## Meta Newsroom

### [Introducing Muse: The World’s First Personal AI Agent Built for Everyone](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)

日期：2026-09-08

Meta 發表 Muse，定位為可主動推進目標與任務的個人 AI agent，能在專屬 Muse Secure VM 中使用瀏覽器、填表、協助寄信或規劃行程，長時間工作後再回報或請求核准。它由 Muse Spark 模型驅動，並以獨立 VM 與使用者可控的存取範圍作為安全與隱私設計基礎。

影響：個人代理正從回答問題轉向代為操作；隔離執行環境、可控授權與人類核准將成為能否大規模部署的關鍵。

### [Inside Meta’s Infrastructure Lab](https://about.fb.com/news/2026/09/inside-metas-infrastructure-lab/)

日期：2026-09-01

Meta 帶領讀者走訪 Menlo Park 的 Infrastructure Lab，展示為下一代 AI 所研發與驗證的硬體基礎設施。內容聚焦於讓大型 AI 系統所需的實體設計、測試與部署流程更貼近實際資料中心條件。

影響：前沿 AI 的差異化不只在模型，還取決於能否快速把硬體、散熱與資料中心設計一起迭代。

## Apple Machine Learning Research

### [DiscoSign: Discourse-Aware Text to Sign Language Gloss Translation](https://machinelearning.apple.com/research/discosign-gloss-translation)

日期：2026-09

Apple 研究人員參與的 DiscoSign 提出以 LLM 為核心的模組化手語 gloss 翻譯框架，將空間指涉、問答子句與概念—gloss 一致性等篇章層級現象納入處理。研究也設計專門評估指標，實驗顯示可改善跨句的空間一致性與實體追蹤，同時維持單句翻譯品質。

影響：可近用性翻譯若只追求逐句正確仍不足；把篇章脈絡納入模型與評估，才更接近自然手語的理解與生成需求。

### [Putting Captions to the Test: Evaluating Video Caption Quality through Multiple-Choice Question Answering](https://machinelearning.apple.com/research/video-caption-quality)

日期：2026-09

Apple 研究人員參與的研究提出 CapQuiz，以人工驗證的細粒度選擇題評估影片描述能否忠實傳遞重要視覺資訊，而非只與單一參考文字做詞彙比對。其 CapF1 指標合併事實正確性與資訊涵蓋度，作者報告這套方式與人類評價的相關性優於既有方法。

影響：多模態模型的品質衡量正轉向資訊保真與可解釋診斷，這可避免把不同但同樣正確的描述錯判為低品質。

## 今日整體趨勢

- **Agent 的重心轉向可執行工作流**：ToolGrad、Tunix 與 Muse 都將重點放在可驗證的工具操作、長時間任務與人類設定的邊界。
- **擴展瓶頸在系統與基礎設施**：NVIDIA 的 MoE 通訊最佳化、OpenAI 的資料平面與 Meta 的資料中心研發，皆說明模型效能需由完整系統支撐。
- **可信任性走向可度量與可治理**：從行為評測與資料權限，到私有 VM 與更貼近人評的多模態指標，產品化的關鍵是能追溯、限制並驗證 AI 行為。
