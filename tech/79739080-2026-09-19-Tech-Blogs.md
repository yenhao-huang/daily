## Google Research

### [以生成式 UI 協助教師建立互動式學習內容](https://research.google/blog/the-future-of-practice-enabling-teachers-to-create-learning-interactives-with-generative-ui/)

發布日期：2026-09-17

Google Research 發表教育用生成式 UI 實驗，讓教師依課程目標動態建立具互動關卡、提示、回饋與解題示範的 STEM 模擬。系統以教學設計原則與自我修正評估迴圈檢查課程目標、可解性與視覺品質，並先由教師審核後才加入內容庫；目前公開超過 30 個英文範例，亦規劃在學校中試行。

影響：生成式介面把製作互動教材的成本降至教師可參與調整的程度，但品質控管與人類驗證仍是擴大使用的關鍵。

## Google Developers

### [為何客戶端 SDK 生成應成為開放基礎設施](https://developers.googleblog.com/why-client-sdk-generation-belongs-in-the-open/)

發布日期：2026-09-17

Google 與 Speakeasy 合作，將其 OpenAPI 客戶端程式碼生成套件以 AGPLv3 開源，並已用於 Google GenAI 的 Interactions、Agents 與 Webhooks API SDK。該工具可產生 Python、TypeScript、Go、Java 等七種語言的具型別、SSE、重試與分頁支援 SDK，也能編譯供代理直接使用的 CLI 與文件 MCP server。

影響：將 API 介面定義到 SDK、CLI 與代理工具的轉譯鏈開放化，可降低專有供應商中斷造成的平台風險，並提高開發與 AI 代理整合的一致性。

## OpenAI News

### [推出 Astra for Law](https://openai.com/index/astra-for-law/)

發布日期：2026-09-17

OpenAI 推出 Astra for Law，將 GPT-6 Astra 配置為面向律所與法律科技公司的 AI 基礎，結合法律搜尋索引、法律分析與寫作指令，以及機密工作所需的隱私與治理控制。該系統可檢索超過 2.3 億個美國判例、法規與行政決定來源，並將透過 ChatGPT/Codex 的 Trusted Access 先提供給選定律所，API 版則規劃後續推出。

影響：高風險專業領域的模型部署正轉向「專用模型設定＋可追溯資料來源＋治理控制」的整合方案，而非僅依賴一般型聊天介面。
