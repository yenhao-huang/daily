## NVIDIA Developer Blog

### Deploy an Open Model from Checkpoint to Inference in Two Commands with NVIDIA TensorRT Model Connect

- **日期：** 2026-08-28
- **摘要：** NVIDIA 推出開源參考實作 TensorRT Model Connect，讓開發者把 Hugging Face 模型或本機 checkpoint 建成部署 bundle，再由原生 C++ 應用載入推論。工具包處理模型映射、TensorRT engine 建置、前後處理與執行協調，並提供語意層與模組層兩種 API，也能透過 TVM FFI 接入自訂 GPU kernel。
- **原文連結：** 📎 https://developer.nvidia.com/blog/deploy-an-open-model-from-checkpoint-to-inference-in-two-commands-with-nvidia-tensorrt-model-connect/
- **影響：** 它明顯降低開放模型從 Python 生態走向無 Python、原生 C++ 生產環境的整合成本。
