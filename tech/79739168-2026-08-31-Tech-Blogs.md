- 影響：自動生成工具使用測試可讓快速演進的 MCP 生態獲得更具覆蓋率且較低成本的持續評估。

### LLMs Are Not (Consistently) Bayesian

- 日期：2026-08-13
- 摘要：研究用 information processing gap 衡量 LLM 更新機率信念時偏離貝氏更新的程度，發現不同提示與整合證據方式會產生顯著差異。部分非貝氏啟發式方法反而在下游任務勝過精確更新，暗示模型內部世界模型可能存在錯置。
- 原文連結：📎 https://machinelearning.apple.com/research/llms-not-consistently-bayesian
- 影響：這項診斷框架有助於評估醫療、科學與法律等高不確定性領域中的 LLM 推論可靠度。

### From Preferences to Principles: Rubric-Based Alignment for Grounded Knowledge Answers

- 日期：2026-08-06
- 摘要：Apple 提出以檢索證據為基礎、依問題動態產生多維 rubric 的 reward framework，細分組織、grounding 與指令遵循等品質。相較 instruction-tuned baseline 平均提升 6.5%，也優於單層 rubric。
- 原文連結：📎 https://machinelearning.apple.com/research/rubric-based-alignment
- 影響：可解釋且細粒度的 reward 設計，可能成為提升 RAG 答案可信度的重要後訓練方法。

## 今日整體趨勢

1. **Agent 工程進入平台化階段**：從 MCP 測試生成、插件封裝、Managed Agents 到組織管理工具，重點由模型能力轉向可移植、可營運、可持續評估的完整系統。
2. **安全邊界與內容可信度成為核心基建**：sandbox containment、模型供應鏈事件回應、帳戶保護與 C2PA 本機驗證，都顯示安全與 provenance 已從附加功能升級為產品預設。
3. **算力競爭轉向全堆疊效率**：新推論晶片、高頻寬互連、TPU 編譯最佳化與資料中心冷卻同時演進，效能、能耗、散熱與部署速度必須一起最佳化。
