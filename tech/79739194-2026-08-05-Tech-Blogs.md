## NVIDIA Developer Blog

### Beyond VLAs: How World Action Models Reshape Robot Manipulation

- **日期：** 2026-08-04
- **摘要：** NVIDIA 認為傳統視覺—語言—動作模型（VLA）擅長語意理解，卻欠缺預測物理世界如何演變的能力；世界動作模型（WAM）則以影片世界模型為骨幹，同時預測動作與未來狀態。文章以 Cosmos 3 與 DROID policy 為例，指出 WAM 可利用更廣泛的互動資料、提升開放環境泛化，並以較少示範適配新機器人。
- **原文連結：** https://developer.nvidia.com/blog/beyond-vlas-how-world-action-models-reshape-robot-manipulation/
- **影響：** 機器人基礎模型的競爭焦點正由「看懂並輸出動作」轉向內建物理預測能力，將牽動資料蒐集、模擬與邊緣部署架構。

### Generate Trajectories, Reasoning Traces, and Auto-Labels with NVIDIA Alpamayo 2 Super

- **日期：** 2026-08-04
- **摘要：** Alpamayo 2 Super 是開放權重的 340 億參數自駕推理 VLA，結合 Cosmos 3 Super Reasoner 與擴散式 Action Expert，可從最多七路相機同時產生軌跡、因果推理、meta-actions、場景問答與自動標註。共同模型可作為 policy teacher、評估 critic、資料引擎與客製化起點，降低自駕研發中多模型分立的成本。
- **原文連結：** https://developer.nvidia.com/blog/generate-trajectories-reasoning-traces-and-auto-labels-with-nvidia-alpamayo-2-super/
- **影響：** 自駕團隊可用同一套可解釋的多任務模型串接資料、訓練與驗證流程，加速長尾場景分析與模型迭代。

## Google Research Blog

### Science One Framework: A verifiable autonomous research framework via Chain-of-Evidence

- **日期：** 2026-07-30
- **摘要：** Google Research 提出 Chain-of-Evidence（CoE），要求研究產物中的引用、數值、方法與結論都能追溯至真實證據，並以 Science One Framework 實作從文獻檢索、平行實驗到聲明驗證的完整流程。其 CoE Audit 會重新執行程式、核對文獻及方法與程式的一致性；官方結果顯示可消除幽靈引用，同時維持具競爭力的研究效能。
- **原文連結：** https://research.google/blog/science-one-framework-a-verifiable-autonomous-research-framework-via-chain-of-evidence/
- **影響：** 自主科研代理的評價標準正從「能寫出論文」升級為「每項主張都可稽核與重現」。

## Google Developers Blog

### A unified API for AI model routing

- **日期：** 2026-08-04
- **摘要：** Google Cloud API Gateway 公開預覽模型路由功能，讓開發者以 OpenAPI 3.x 規格設定虛擬模型名稱與後端映射，並用 OpenAI 相容請求動態路由到 Gemini、Claude 或 OpenAI OSS-GPT。Gateway 同時負責 payload 轉換、限流與 token 追蹤，也可與企業代理平台的安全治理層搭配。
- **原文連結：** https://developers.googleblog.com/a-unified-api-for-ai-model-routing/
- **影響：** 多模型應用的切換與治理正快速下沉到雲端閘道層，可降低自建 proxy 的維運負擔與供應商鎖定。

### Scaling real-time AI agents with session-aware load balancing

- **日期：** 2026-08-03
- **摘要：** 即時語音代理依賴長連線與有狀態雙向串流，單看 QPS 或 CPU 容易低估已承諾的工作量。文章建議由應用程式精確追蹤活躍 session，再把 session 數與 CPU／記憶體等即時利用率合併成混合式路由訊號，並特別處理中斷、逾時與 ghost session。
- **原文連結：** https://developers.googleblog.com/scaling-real-time-ai-agents-with-session-aware-load-balancing/
- **影響：** 即時代理進入生產後，容量規劃與負載平衡必須從無狀態 Web 指標轉向會話生命週期感知。
