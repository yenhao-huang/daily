## NVIDIA Developer Blog

### [How Full-Stack NIM Optimizations Deliver 2.5x More Users on Nemotron 3 Ultra](https://developer.nvidia.com/blog/how-full-stack-nim-optimizations-deliver-2-5x-more-users-on-nemotron-3-ultra/)

發布：2026-09-10

NVIDIA 將針對 Nemotron 3 Ultra 的核心、平行化、快取／狀態重用、排程及推測式解碼打包為 NIM 最佳化服務堆疊。在 4×B200、每位使用者 50 TPS 的測試設定中，該堆疊達到 1,997 tokens/s，較基準方案約提升 2.5 倍。

影響：把多項推論調校封裝為可部署、可量測的組態，可降低團隊在延遲、吞吐與併發間取捨的工程成本。

### [High-Throughput Structure Prediction with BioNeMo Inference Runtime](https://developer.nvidia.com/blog/high-throughput-structure-prediction-with-bionemo-inference-runtime/)

發布：2026-09-10

BioNeMo Inference Runtime 提供從資料解析到結構輸出的端到端流程，也可直接整合 PyTorch 模組；Ray 執行器能讓每張 GPU 載入完整模型副本以處理獨立工作項目。官方以 8×H100、1,000 個 human dimer 目標的比較指出，BioIR 加速的 Boltz-2 每 GPU 小時完成 58.5K 個殘基，約為對照實作的 2.9 倍。

影響：蛋白質結構預測可在不大幅改變既有 PyTorch 工作流下，提高大批次生物研究的吞吐與資源效率。

## Google Research

### [Transfer learning for genomic prediction in underrepresented populations](https://research.google/blog/transfer-learning-for-genomic-prediction-in-underrepresented-populations/)

發布：2026-09-03

Google Research 比較歐洲族群資料遷移至較少代表性族群時的多基因風險分數表現，發現當目標族群樣本很小時，外部大型資料可提升預測；但目標資料變多後，對具族群特異遺傳架構的性狀反而可能降低準確度。研究也指出不同性狀的轉折點不同，建模策略應隨樣本量與遺傳共享程度調整。

影響：這為較公平的精準醫療資料設計提供實證依據，凸顯擴充在地、多元生物庫的重要性。

### [A connectomics milestone: Mapping the complete male fruit fly brain](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/)

發布：2026-09-03

Google 與 HHMI Janelia 等合作夥伴發布雄性果蠅完整腦部與中樞神經系統接線圖，含逾 166,000 個神經元與 1.25 億個突觸連結。團隊運用 AI 將電子顯微影像重建為 3D 神經結構，並透過公開視覺化工具與資料集支援後續研究。

影響：完整、可比對的雌雄果蠅神經圖譜可加速神經科學實驗與腦疾病機制研究。

## Google Developers

### [The Anatomy of Harness Engineering: How to Evaluate, Iterate, and Guard AI Coding Agents](https://developers.googleblog.com/the-anatomy-of-harness-engineering-how-to-evaluate-iterate-and-guard-ai-coding-agents/)

發布：2026-09-09

Google 建議評估 AI coding agent 時，不只依賴昂貴且難以診斷問題的端到端基準，而要加入驗證中間行為的快速本地測試。這些微型檢查可針對工具呼叫或檔案變更建立明確斷言，並與較大範圍的基準互補。

影響：可觀測、可重複的 harness 評估有助於團隊安全迭代系統提示與模型版本，減少無法解釋的回歸。

### [Announcing ADK for Kotlin 1.0: Building Production-Ready AI Agents in Kotlin, Android, and Beyond](https://developers.googleblog.com/announcing-adk-for-kotlin-10-building-production-ready-ai-agents-in-kotlin-android-and-beyond/)

發布：2026-09-09

Agent Development Kit for Kotlin 1.0 宣布達到與 Python、Java 核心相對齊的正式版本，提供 Kotlin Multiplatform、KSP 型別安全 function calling、人工介入流程與 context compaction。新版亦導入 Android 導向能力，可結合 LiteRT-LM、Firebase AI、Room 與 AppSearch 支援本機或雲端代理工作流。

影響：Kotlin 與 Android 團隊現在有較完整的生產級代理框架，可將行動端能力納入多代理系統。

## OpenAI News

### [Now everyone can put data to work](https://openai.com/index/put-data-to-work/)

發布：2026-09-10

OpenAI 推出 Data agent，讓使用者以已核准的企業資料來源與檔案作為分析脈絡，支援 Redshift、Datadog、BigQuery、Databricks、Snowflake、Google Drive 與 SharePoint 等。產品重點是讓組織把可控存取的資料直接帶入分析工作，而非在工具間人工搬運脈絡。

影響：企業 AI 的競爭焦點持續從模型能力延伸到受治理的資料連接、權限與可用工作流。

### [Build more natural voice experiences with GPT-Live-1 in the API](https://openai.com/index/introducing-gpt-live-1-in-the-api/)

發布：2026-09-10

GPT-Live-1 以單一模型同時理解輸入與輸出的音訊，改善打斷處理並減少傳統 STT–LLM–TTS 串接架構的延遲與脆弱交接。模型可將推理或工具呼叫委派給後端文字模型，並讓開發者在 system prompt 控制語氣、速度與風格。

影響：即時語音代理可採取更低延遲的架構，同時保留複雜推理與工具操作的擴充性。
