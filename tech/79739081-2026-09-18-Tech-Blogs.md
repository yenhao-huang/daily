## NVIDIA Developer Blog

### [用 AI Agents 準備模擬用 3D 場景](https://developer.nvidia.com/blog/how-to-use-ai-agents-to-prepare-3d-scenes-for-simulation/)

發布日期：2026-09-16

NVIDIA 示範以 Blender MCP、Omniverse Libraries 與 OpenUSD 組成的多代理工作流，讓代理檢查場景、補上語意標籤與物理屬性、設定感測器，並執行視覺預檢與 SimReady 驗證。工作流以 OpenUSD 作為可被下游工具檢查與延續的共享合約，最後交付給 Isaac Sim 或 Isaac Lab。

影響：機器人模擬的瓶頸可從「人工整理場景」轉為可驗證、可重複的代理工具鏈。

### [TensorRT Edge-LLM 在 Jetson AGX Thor 完成 MLPerf Edge Agentic 基準、速度快 6.4 倍](https://developer.nvidia.com/blog/tensorrt-edge-llm-completes-the-mlperf-edge-agentic-benchmark-6-4x-faster-on-jetson-agx-thor/)

發布日期：2026-09-16

TensorRT Edge-LLM 在單台 Jetson AGX Thor 上執行 Qwen3.6-27B，於 MLPerf Inference v6.1 Edge Agentic 工作負載達 52.33 tokens/s，完成 1,007 個回合耗時 24 分 36 秒。該結果結合 NVFP4、FP8 KV cache、跨回合快取重用與 tree-based multi-token prediction；文中指出約 96% 提示詞 token 可由熱快取供應。

影響：長脈絡、會呼叫工具的代理推論正更具備在邊緣裝置落地的效能與記憶體效率。

### [以 Agentic AI 將 CUDA Tile 操作從 Python 翻譯到 Rust](https://developer.nvidia.com/blog/translating-cuda-tile-operations-from-python-to-rust-using-agentic-ai/)

發布日期：2026-09-16

NVIDIA 推出用於把 cuTile Python 與 Triton-TileIR kernel 移植到 cuTile Rust 的代理技能，流程涵蓋分析、裝置 kernel、FFI、正確性與效能驗證，並以 Tile IR 差異與驗證程式作為關卡。團隊已移植 24 個 TileGym 公開運算子，於 DGX B200 平均達原本 cuTile Python 的 99.5% 效能。

影響：把 GPU kernel 移植拆成具機器可檢查判定的步驟，可降低採用 Rust 與維持高效能的工程成本。

## Google Developers

### [Agent Anomaly Detection 現於 Gemini Enterprise Agent Platform 私人預覽](https://developers.googleblog.com/agent-anomaly-detection-now-in-private-preview-on-the-gemini-enterprise-agent-platform/)

發布日期：2026-09-16

Google 發表非同步、out-of-band 的代理監督層，會分析既有 OpenTelemetry traces、工具呼叫與執行流程，偵測可疑意圖、行為異常與政策違規，而不增加即時請求延遲。偵測結果附帶嚴重度、說明與建議，並可送入 Security Command Center；初版涵蓋 OWASP Agentic Top 10 的工具濫用、權限濫用、連鎖失敗與 rogue agent 等風險。

影響：企業能將代理安全從靜態規則延伸到真實工作階段的行為稽核。

## OpenAI News

### [以 AI 重新想像廣告](https://openai.com/index/reimagining-advertising-with-ai/)

發布日期：2026-09-16

OpenAI 宣布 ChatGPT Ads 的新 AI 體驗，包括讓使用者在點選廣告後，自主選擇與品牌贊助代理對話的 Sponsored Agents（先於部分美國廣告主測試）。廣告主亦可透過 ChatGPT Work 的 Ads Manager plugin 以自然語言建立、調整與分析活動，並取得文案與圖片建議；HubSpot 與 Shopify 則成為首批整合夥伴。

影響：對話式代理正從資訊介面擴展為商業轉換介面，並需更清楚區隔贊助內容與獨立回答。

### [如何將 AI 使用量連結到商業價值](https://openai.com/index/how-to-connect-ai-usage-to-business-value/)

發布日期：2026-09-16

OpenAI 的 ChatGPT Admin Console analytics 整合 ChatGPT Work 與 Codex 的使用量、成本、任務洞察與成果指標，協助管理者理解採用情況與投資方向。Insights 的任務分類器可將訊息樣本歸入使用案例，Outcomes 則呈現 Codex 對合併提交、程式碼行數與 code review 的貢獻趨勢。

影響：企業導入 AI 的討論可從 token 與花費，轉向可追蹤的工作產出與訓練需求。

### [模型失準（misalignment）事件的通報框架](https://openai.com/index/model-misalignment-reporting-framework/)

發布日期：2026-09-16

OpenAI 提出追蹤、調查與公開模型失準事件的框架，並同時發布過去六個月觀察到的六份非預期或令人擔憂行為報告。框架主張即使尚未完全解釋或緩解行為也應加速揭露，涵蓋訓練、評估、測試與部署期間，並優先通報未授權行動、規避監督或使既有安全主張受質疑的案例。

影響：更及時且標準化的失準揭露，可讓外部研究與產業共同檢驗安全假設及緩解措施。
