### Arbitrage: Efficient Reasoning via Advantage-Aware Speculation

- 日期：2026（頁面未提供日月）
- 摘要：ARBITRAGE 是 step-level speculative generation 框架，用輕量 router 判斷 draft model 與 target model 哪一方更可能產生較佳推理步驟。它避免在語意等價但 token 不同時不必要地拒絕草稿，並在數學推理基準上以相同準確率把延遲最多降低約 2 倍。
- 原文連結：📎 https://machinelearning.apple.com/research/arbitrage-efficient-reasoning
- 影響：推理模型的下一波效率提升可能來自動態分配「由誰產生下一步」，而非只做 token 級加速。

### Beyond Next-Token Prediction: A Performance Characterization of Diffusion versus Autoregressive Language Models

- 日期：2026（頁面未提供日月）
- 摘要：研究比較 diffusion language models 與 autoregressive models 的理論和實測效能，指出 DLM 雖能利用 token 位置並行提高 arithmetic intensity，但長 context 擴展不佳。Block-wise decoding 可改善長序列伸縮性，而批次推論目前仍由 AR 模型取得較佳 throughput；DLM 的關鍵則是減少 sampling steps。
- 原文連結：📎 https://machinelearning.apple.com/research/diffusion-autoregressive-performance
- 影響：非自回歸語言模型要進入實際部署，仍須跨過採樣步數與長上下文效率兩道硬體效能門檻。
