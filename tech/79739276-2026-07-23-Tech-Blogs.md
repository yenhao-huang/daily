### Make Long-Running NVIDIA TensorRT Engine Builds Observable and Cancelable in Python or C++

- **日期：** 2026-07-22
- **摘要：** TensorRT 的大型、強型別模型建置可能耗時數分鐘，傳統整合卻缺乏進度與中止能力。文章示範以 `IProgressMonitor` 在 Python/C++ 呈現巢狀進度，並透過回呼安全取消建置，讓 IDE、服務與長時間運作的 AI agent 不再因無回應流程浪費 GPU 時數。

### Setting a World Record for MoE Pre-Training on NVIDIA GB300 NVL72

- **日期：** 2026-07-21
- **摘要：** NVIDIA 表示 GB300 NVL72 以 256 張 GPU 預訓練 DeepSeek-V3 671B，達到每 GPU 1,648 TFLOPs，並在擴至 1,024 張 GPU 時維持近 97%–98.5% 的單卡效能。成果凸顯 MoE 訓練的瓶頸已由純運算逐漸轉向 all-to-all 通訊，必須靠 NVLink、800Gb/s 網路與 Megatron Core、TorchTitan、JAX 的共同最佳化解決。
- **原文連結：** 📎 https://developer.nvidia.com/blog/setting-a-world-record-for-moe-pre-training-on-nvidia-gb300-nvl72/
- **影響：** 大型 MoE 的競爭焦點更明確地轉向整櫃級協同設計與持續軟體最佳化，而非只比較晶片峰值算力。

### Towards demystifying the creativity of diffusion models

- **日期：** 2026-07-15
- **摘要：** 研究從數學角度解釋擴散模型為何能產生訓練資料之外的新樣本：神經網路訓練與正則化會讓 score function 出現平滑化，促使去噪軌跡在資料點之間插值。這將生成模型的「創造力」連結到可分析的 score smoothing，而非單純視為黑箱湧現。

- **影響：** 為理解、調控生成模型的新穎性與記憶化風險提供較可驗證的理論基礎。

### Accelerating Text-to-Video Generation with Calibrated Sparse Attention

- **日期：** 未提供
- **摘要：** CalibAtt 透過離線校準找出跨輸入穩定、可略過的區塊級注意力連結，再為不同層、head 與擴散時間步編譯最佳化運算。方法不需重新訓練，在 Wan 2.1 14B、Mochi 1 等模型達到最高 1.58 倍端到端加速，同時維持影像品質與文字對齊。

- **影響：** 訓練後稀疏化可降低高品質影片生成成本，尤其適合硬體資源受限的部署場景。

### Environment-free Synthetic Data Generation for API-Calling Agents

- **日期：** 未提供
- **摘要：** 研究僅需 API 規格，便以 LLM 即時模擬具狀態環境、生成任務與 API 回應，再由教師代理解題、判別模型篩選軌跡。AppWorld 與 OfficeBench 結果顯示，不建置可執行後端也能產生有效的 API agent 微調資料。

- **影響：** API agent 的訓練資料成本可能大幅下降，但模擬偏差與狀態一致性會成為新的品質關卡。
